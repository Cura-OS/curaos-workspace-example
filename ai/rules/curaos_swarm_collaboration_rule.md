# Native collaboration

Use subagents only when the owner or applicable instructions authorize parallel agent work. Choose finite ready tasks from Rice, assign disjoint source ownership and retain exact operation handles. Pack compatible repository work before parallel dispatch; serialize overlapping working trees, generated inputs or dependencies.

The parent coordinates actual remaining acceptance criteria and integration. Workers publish qualified evidence, unresolved dependencies and exact source heads into Rice. No private local tracker or run directory is authoritative. A completed worker or status update does not complete the goal.

Keep each worktree's mutable dependencies separate. Preserve unrelated dirty work and recovery. Reuse successful evidence only when the owning canonical validator confirms unchanged inputs and scope. Keep pending harness questions as native Rice request references with answers on stdin.

See [maintained toolkit consumption](../../docs/agents/rice-toolkit.md).
