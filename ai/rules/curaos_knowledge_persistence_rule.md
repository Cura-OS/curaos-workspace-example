# Working knowledge through Rice

Retrieve current tasks and relevant knowledge through configured Rice search/context/document reads. Source-relative paths are stable document identities, not local files to recreate.

Create and edit working tasks, specs, plans, research and decisions through the native document API with exact expected revisions. Verify content, history and graph relationships. Preserve prior bytes and links before deleting a migrated working copy. No local planning file, handover, issue ledger, SQLite database or archived fallback is an execution authority.

Keep code, licenses, required bootstrap configuration and product documentation in Git. Keep historical executable source outside active package/test discovery. Use native Git for code history and the installed project skills for Rice publication. Credentials use configured secret references, never document contents.

See [maintained toolkit consumption](../../docs/agents/rice-toolkit.md).
