# Symphony alignment through Rice

Select the matching maintained workspace playbook through the configured Rice toolkit. This template owns no executable workflow copies or independent tracker backend.

- Native Rice tasks, dependencies, policy/provenance documents and fenced execution records are the authority. Use exact revision guards and immutable history; reconcile conflicts rather than overwriting.
- Both Codex and Claude use configured project Rice tools and skills plus their own native execution capabilities. Do not route one harness through another harness merely for convenience.
- Workflow answers use request IDs and JSON stdin; result references identify remote Rice records, not result files. Private lease grants stay in client memory/stdin, never public content.
- Preserve unrelated work, bundle compatible rows, isolate conflicting working trees and retain the owning project's checks, review, provenance and landing contracts.
- Retries require changed inputs or bounded temporary-failure backoff. Observe actual live operation handles; a status update or gate wait does not suspend authorized work.
